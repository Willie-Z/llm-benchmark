对话分析 历史+当前 · 本地向量检索 · LLM 分析

提问验收结果，助手先从本地向量库检索相关历史验收片段，连同最近一次结果一起交给 LLM 分析。分析员 LLM 复用下方所选通道的 Endpoint / Key / 模型（经本机代理转发，Key 不出本机）。验收结果与通道配置均存 localStorage，刷新不丢。

向量库：浏览器内 TF-IDF + 余弦相似（轻量本地实现，无外部依赖）；历史结果随 localStorage 持久化。分析调用经本地代理转发到所选通道。
